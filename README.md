# 📊 Basic Conditional Formatting in Excel

## 📌 Project Overview
This project demonstrates how to use Conditional Formatting in Microsoft Excel to automatically highlight important sales values in a retail sales dataset.

## 🎯 Objective
To improve report readability and identify the highest and lowest sales values using automatic formatting rules.

## 📂 Dataset
The dataset contains 15 retail products with the following columns:
- Product
- Category
- Sales

## 🛠️ Tools Used
- Microsoft Excel
- Conditional Formatting
- Excel Tables

## 📋 Formatting Rules Applied

| Rule | Description |
|---|---|
| Top 10 Items | Highlights the highest 10 sales values |
| Bottom 10 Items | Highlights the lowest 10 sales values |
| Greater Than | Highlights sales above 20,000 |
| Less Than | Highlights sales below 20,000 |
| Duplicate Values | Identifies repeated sales values |

## 📸 Project Features
- Automatic highlighting of sales values.
- Identification of high and low sales.
- Easy-to-read sales reports.
- Separate Rules List worksheet.
