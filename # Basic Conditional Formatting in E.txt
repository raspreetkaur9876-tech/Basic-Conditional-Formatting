# Basic Conditional Formatting in Excel

## Project Overview
This project demonstrates the use of Basic Conditional Formatting in Microsoft Excel to highlight important sales values automatically.

## Objective
To improve report readability and identify the highest and lowest sales values using Excel formatting rules.

## Dataset
Retail Sales Dataset containing 15 products with:
- Product
- Category
- Sales

## Conditional Formatting Rules
1. **Top 10 Items:** Highlights the highest 10 sales values.
2. **Bottom 10 Items:** Highlights the lowest 10 sales values.
3. **Greater Than:** Highlights sales values above 20,000.
4. **Less Than:** Highlights sales values below 20,000.
5. **Duplicate Values:** Identifies repeated sales values.
